# T.C. BUZDOLABI ARTIK YEMEĞİ VERASET İLAMI GENEL MÜDÜRLÜĞÜ

## Resmi Protokol Yazılımı — Sürüm 47.0 (Küf Onaylı)

Bu yazılım, buzdolabının üçüncü rafında, şeffaf bir kapta, üzerine alüminyum folyo gevşekçe kapatılmış halde bekleyen **artık yemeğin** hukuki statüsünü kesinleştirir.

Yemek ölmemiştir. Yemek **terk etmiştir**.

Terk eden yemeğin terekesi açılır. Mirasçılar şunlardır:

1. Küf (birinci derece, kanuni)
2. Pişmanlık (ikinci derece, manevi)
3. Ev arkadaşı (üçüncü derece, şüpheli)
4. Kedi (dördüncü derece, fiili zilyet)
5. Çöp kutusu (son çare, icra dairesi)

### Kurulum

```bash
python3 veraset.py
```

Bağımlılık yoktur. Sadece Python 3. Standart kütüphane yeterlidir çünkü küf de standarttır.

### Kullanım

Program sorar:
- Yemeğin adı (veya tahmini adı)
- Kaç gündür rafta durduğu
- Kapak kapalı mı

Sonra **bağlayıcı** bir veraset ilamı basar. İtiraz süresi: kapağı açana kadar. Kapağı açtıysanız süre dolmuştur.

### Hukuki Uyarı

Bu yazılım:
- Noter onaylı **gibi** durur
- Mahkeme kararı **değildir**
- Yemeği kurtarmaz
- Kokuyu dağıtmaz
- Sadece evrak üretir

ISO-KUF-09 belgesi başvuru aşamasındadır. Başvuru evrakı da buzdolabındadır.

### Sık Sorulan Sorular

**Yemeği yersem ne olur?**  
Mirasçılık sıfatınız düşer. Mideye geçen tereke artık bu protokolün konusu değildir.

**Tarih geçmiş yoğurt da kapsama girer mi?**  
Evet. Yoğurt, bu müessesenin kurucu ortaklarındandır.

**Neden Türkçe?**  
Çünkü küf evrenseldir ama dilekçe dili yerlidir.
